# Interface references

Use [CONNECTORS.csv](../CONNECTORS.csv) for the board-facing schematic cavity map and [SYSTEM_HARNESS.csv](../SYSTEM_HARNESS.csv) for system paths. The pin/net names were compared with the saved schematic; they do not establish PCB parity, cable wiring, electrical limits or physical qualification.

The other files retain MTi, wall-interface, OEM, camera, jog and Teensy references. Earlier supplier, cart and purchase observations may be outdated.
