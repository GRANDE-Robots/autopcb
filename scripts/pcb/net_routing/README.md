# net_routing

The autoroute engine behind `autopcb route` and `placement-study`. The controller and runner search in rounds on private copies, the backend and rules read and judge native copper, and relocation, rework and recovery repair nets that stall. Progress is kept in source-bound checkpoints, so a run can be resumed or renewed after the sources or tools change.
