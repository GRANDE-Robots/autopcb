# verification

The unit tests and the audit tools. Run the whole suite with `python scripts/run.py --project . test`, or one module with `python -m unittest verification.<module>` from `scripts/`. `audit_code_health.py` implements `check code`, which audits the class, header, docstring and README rules against `code_rules_baseline.json`. The other `audit_*` and `inspect_*` tools read a KiCad project and report on it.
